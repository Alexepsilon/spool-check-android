# Install Spool Check on Android

Two languages below — pick yours.

---

## English

**1. Download the APK**

Tap this link on your Android phone:

https://github.com/Alexepsilon/spool-check-android/releases/latest/download/spool-check-v1.2-debug.apk

Chrome may warn that "this type of file can harm your device" — that's a generic warning shown for every APK download. Tap **Download anyway**.

**2. Open the file**

When the download finishes, tap the notification, or open Files → Downloads → tap **spool-check-v1.2-debug.apk**.

**3. Allow install from this source (first time only)**

Android will ask: *"For your security, your phone is not allowed to install unknown apps from this source."*

Tap **Settings**, then turn on **Allow from this source**, then back out.

**4. Install**

Tap **Install**. You may see a Play Protect screen ("App not checked by Google") — tap **Install anyway**.

**5. Open the app**

Tap **Open**, or find **Spool Check** in your app drawer.

## Nederlands

**1. Download de APK**

Tik op deze link op je Android-telefoon:

https://github.com/Alexepsilon/spool-check-android/releases/latest/download/spool-check-v1.2-debug.apk

Chrome geeft mogelijk een waarschuwing dat "dit type bestand schadelijk kan zijn" — dat is een standaard melding bij elk APK-bestand. Tik op **Toch downloaden**.

**2. Open het bestand**

Als de download klaar is, tik op de melding, of open Bestanden → Downloads → tik op **spool-check-v1.2-debug.apk**.

**3. Sta installatie toe (alleen de eerste keer)**

Android vraagt: *"Voor je veiligheid mag je telefoon geen onbekende apps installeren via deze bron."*

Tik op **Instellingen**, zet **Toestaan vanuit deze bron** aan, en ga terug.

**4. Installeer**

Tik op **Installeren**. Mogelijk verschijnt een Play Protect scherm ("App niet door Google gecontroleerd") — tik op **Toch installeren**.

**5. Open de app**

Tik op **Openen**, of zoek **Spool Check** in je app-overzicht.

## Updates

When a new version comes out, you'll get a fresh APK link. Install it the same way — Android will replace the existing app and keep your data (deliveries, scans) intact.

The "allow from this source" prompt should not appear on subsequent installs.

## Requirements

- Android 7.0 (Nougat) or newer
- Camera (for scanning tags)
- ~100 MB storage

## Troubleshooting

- **"App not installed"** — usually means you already have a newer version. Uninstall the old one first, or ask for the matching APK.
- **Camera shows black** — open Android Settings → Apps → Spool Check → Permissions → enable Camera.
- **Cannot open .xlsx** — the file picker needs to see the file. Save the transport list to your phone's Downloads or open it from Drive/email first.
